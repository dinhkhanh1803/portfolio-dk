# Trần Đình Khánh — Portfolio

Portfolio cá nhân được xây dựng bằng Next.js, React và Tailwind CSS.

## Chạy trên máy local

Yêu cầu Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000) trên trình duyệt.

## Các lệnh khác

```bash
npm run build
npm start
npm run lint
```
